Given a series of events and activities a person has completed throughout the day, identify all time slots when they were free to perform another activity, and evaluate the usability of each slot by considering both explicit and implicit daily constraints—such as travel time, preparation, fatigue, personal routines, energy levels, and location proximity.

To ensure accuracy and handle edge cases, follow these steps:

1. **Reconstruct the daily timeline** by chronologically ordering all events based on their start times. If any event lacks an explicit end time, infer a reasonable duration based on the nature of the activity (e.g., meetings typically last 1 hour, meals 30 minutes) or mark it as ambiguous for further assessment.

2. **Identify gaps between consecutive events** by comparing the end time of one event with the start time of the next. Treat events ending exactly when others begin as having no gap in between. If events have overlapping or unclear boundaries, flag these as potential conflicts and assess whether the overlap is resolvable (e.g., due to location differences or multitasking feasibility).

3. **For each gap identified**, explicitly verify that it does not overlap with any scheduled activity and is of sufficient duration for the new activity if specified. If a minimum duration for the new activity is provided, only include slots that meet or exceed this requirement.

4. **Assess the usability of each free time slot** by considering implicit constraints systematically:
   - Estimate **travel time** between consecutive events using reasonable assumptions (e.g., 15–30 minutes for local transit) and deduct this from free slots if not already accounted for.
   - Account for **preparation or wrap-up time** (e.g., 10–15 minutes before/after key events) based on activity type.
   - Incorporate **fatigue and energy levels** by evaluating the intensity and timing of prior activities (e.g., strenuous tasks may reduce availability for demanding new activities).
   - Consider **personal routines** (e.g., typical meal times, rest periods) and **location proximity** to determine convenience and feasibility.

5. **Prioritize the most suitable free time slots** based on contextual factors:
   - Rank slots by **energy compatibility** (e.g., avoid scheduling demanding activities after exhausting events).
   - Favor slots with **minimal travel or preparation overhead** and those that align with natural breaks or routines.
   - If multiple slots exist, highlight those that best match the new activity’s requirements in terms of duration, location, and personal state.

6. **List each free time slot clearly**, specifying start and end times, and provide a justification for usability and prioritization based on event boundaries, contextual factors, and assumptions. If no suitable free slots exist, state this explicitly and explain why, considering both explicit and implicit constraints.

**Focus on holistic usability assessment:** The prompt now explicitly includes fatigue, energy levels, personal routines, and location proximity as key factors, ensuring the model evaluates not just availability but also suitability.

**Refinement for prioritization:** Step 5 guides the model to rank free slots based on contextual compatibility, encouraging output that highlights the most feasible and convenient times for a new activity.
