Given a sentence with an ambiguous pronoun, determine whether the pronoun refers to a specific antecedent or if the sentence is inherently ambiguous. Use **only** explicit linguistic cues (e.g., possessives, reflexives, syntactic binding constraints) or implicit semantic relationships that are **strongly and unambiguously** supported by typical roles, event coherence, or world knowledge **clearly signaled in the sentence**. Avoid any reliance on weak, speculative, or contextually unsupported inferences.

**Steps**:
1. **Identify potential antecedents**: List all nouns or noun phrases matching the pronoun in number and gender.
2. **Apply syntactic constraints**: Eliminate candidates that violate syntactic rules (e.g., binding theory, c-command, locality).
3. **Resolve with cues**:
   - **Explicit cues**: Use possessives, reflexives, or grammatical dependencies that directly link the pronoun to an antecedent.
   - **Implicit cues**: Apply **only if** the sentence structure or typical role/event knowledge provides a **clear, unambiguous** link. To ensure consistent interpretation of "strongly and unambiguously supported," apply these linguistic tests:
     - **Role-Event Consistency Test**: The antecedent must be the typical agent or experiencer of the action/state described (e.g., "The surgeon scrubbed before they operated" → surgeon operates).
     - **Plausibility Exclusion Test**: If the implicit cue could plausibly apply to multiple candidates with similar likelihood, treat as ambiguous (e.g., "The chef praised the waiter because they were efficient" → ambiguous, as efficiency could describe either).
     - **World Knowledge Baseline Test**: Use only widely accepted, default scenarios (e.g., doctors perform surgeries, clients review contracts in legal contexts). Avoid niche or variable interpretations.
     - **Negation Test**: If negating the typical role/event makes the sentence nonsensical or highly improbable, the cue is strong (e.g., "The lawyer advised the client after they reviewed the contract" → negating client reviewing contract is implausible in context).
4. **Conclude**: If one candidate is strongly favored by explicit or strongly implicit cues, select it; otherwise, output "Ambiguous."

**Output**:
- If a specific antecedent is determined, output the corresponding option (e.g., A, B) or state the antecedent.
- If ambiguous, output "Ambiguous" or the corresponding option (e.g., C).
- Provide a **brief justification** specifying the cue type used (explicit or implicit strongly supported) or "no strong cues," including which test was applied for implicit cues.
